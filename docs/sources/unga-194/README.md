# UN General Assembly resolution 194 (III), paragraph 11

The start screen of The Story of the Land quotes the opening of paragraph 11, the right of return, in Arabic and English.
`StartScreenTests` checks that each quoted line is a word-for-word passage of these files.

- English: the resolution as adopted, A/RES/194 (III), 11 December 1948 (https://www.un.org/unispal/document/auto-insert-177271/, UN Digital Library https://digitallibrary.un.org/record/210025).
- Arabic: the official United Nations Arabic translation, as quoted by Jaber Suleiman, "The right of return", Muwatin Institute, Birzeit University (https://muwatin.birzeit.edu/ar/print/7381). Check against the UN Digital Library Arabic PDF before release.
